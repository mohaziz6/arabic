# لعبة المحاكمة — مواصفة اللعب والوكيل

أول لعبة تُبنى في ديوان التحدي، وتُبنى كشريحة عمودية كاملة: واجهة، وخادم، وقاضٍ يحكم.
منها يُستخرج «الوكيل الكبير» لاحقاً حين تُبنى اللعبة الثانية — لا يُخمَّن مقدماً.

## الفكرة

شاعر متهم في قضية. لاعب يترافع عنه (**المحامي**)، ولاعب يترافع ضده (**المدعي العام**).
القاضي وكيل ذكاء اصطناعي يسمع الطرفين، يقيّم، ويحكم.

## مسار الجلسة

```
الوكيل الكبير (آلة حالات في الخادم)
│
├── محاكمة ١ ──┐
├── محاكمة ٢   ├── أول من يكسب حكمين يفوز بالجلسة
└── محاكمة ٣ ──┘   (الأدوار تتبدّل كل محاكمة: المحامي يصير مدعياً)
```

وكل محاكمة:

| # | المرحلة | المدة | من يتكلم |
|---|---|---|---|
| ١ | عرض القضية | — | القاضي |
| ٢ | مرافعة الادعاء | ٩٠ ثانية | المدعي |
| ٣ | مرافعة الدفاع | ٩٠ ثانية | المحامي |
| ٤ | جولة الردّ | ٤٥ ثانية لكل طرف | الاثنان |
| ٥ | الحكم | — | القاضي |

أربع مرافعات، وتنتهي المحاكمة في نحو خمس دقائق.

## القضية

يولّدها الوكيل في كل محاكمة، **عبثية مضحكة** بروح الاستهبال:
«شاعر متهم بسرقة بحر الطويل»، «متهم بقتل قافية عمداً مع سبق الإصرار».

تُولَّد مرة واحدة في بداية المحاكمة وتُخزَّن، فتُقرأ من التخزين المؤقت في كل نداء بعدها.

## بطاقات الأكشن

لكل لاعب **أربع بطاقات** تدوم الجلسة كلها (لا المحاكمة الواحدة)، ويلعب **بطاقة واحدة
كحد أقصى في كل مرافعة**. البطاقة اختيارية: تلعبها إن رأيت أنك قادر.

| # | البطاقة | ما تفرضه | من يولّد المحتوى |
|---|---|---|---|
| ١ | **تكلّم فصحى** | مرافعتك كلها بالفصحى بلا لهجة | لا محتوى — قاعدة فقط |
| ٢ | **أدخل المثل** | تُدخل مثلاً بعينه في كلامك بسياق سليم | الوكيل يولّد المثل |
| ٣ | **أدخل البيت** | تُدخل بيت شعر بعينه في مرافعتك | الوكيل يولّد البيت |
| ٤ | **اعتراض** | تقاطع خصمك أثناء مرافعته، والقاضي يقبل أو يرفض | الوكيل يحكم على وجاهته |

**الاعتراض يوقف مؤقّت الخصم** حتى يفصل القاضي — وإلا صار سرقة وقت لا حجة.

**المخاطرة والمكافأة:** لعبت البطاقة ونجحت ← نقاط إضافية. لعبتها وفشلت ← خصم.
لم تلعبها ← لا شيء. فاللاعب يقرر متى يخاطر.

**البطاقات تعيش في الخادم فقط.** لو أُرسلت للمتصفح تُقرأ من أدوات المطور في ثانية.

## القاضي

شخصية واحدة الآن: **صارم وعاقل، لكن يغريه إدخال الشعر في المحاكمة** — يرفع الدرجة
لمن يحسن الاستشهاد، ويقسو على من يتكلف. (شخصيات أخرى لاحقاً.)

يقبل الفصحى واللهجة النجدية معاً إلا حين تفرض البطاقة الأولى الفصحى.

## بنية الوكيل

**أغلب ما نسميه «وكيلاً» ليس وكيلاً** — وهذا يوفّر أكثر من نصف التكلفة والتعقيد.

### الوكيل الكبير: آلة حالات، لا نموذج لغوي

يملك: اللاعبَين، أدوارهما، أي محاكمة نحن فيها، النتيجة، ومن يتكلم الآن.
كود عادي في الخادم — حتمي وقابل للتنقيح ومجاني. لا يُسأل النموذج «مين دوره الآن».

### قاضي المحاكمة: ثلاث دوال بمخرج منظّم

ليس حلقة أدوات (tool loop) — نحن نتحكم في الترتيب، والنموذج يجيب ويسكت:

```
generateCase()                →  { التهمة، الشاعر المتهم، الأدلة، المثل، البيت }
judgeSpeech(نص, دور, بطاقة)   →  { تعليق، درجة، هل نُفّذت البطاقة }
deliverVerdict(كامل الجلسة)    →  { الفائز، الحيثيات، نص الحكم المنطوق }
```

كل واحدة نداء واحد بـ `output_config.format` يضمن JSON مطابقاً للمخطط، لا نصاً حراً يُحلَّل.

**النموذج:** `claude-opus-5` مع تفكير تكيّفي. ملاحظة: `temperature` أُزيل من Opus 5
ويُرفض بخطأ ٤٠٠ — فثبات الحكم يجي من سلّم درجات مكتوب صراحة ومخرج منظّم، لا من ضبط العشوائية.

## الصوت

`transcribe()` واجهة صغيرة، تنفيذها الأول **Web Speech API** في المتصفح — مجاني، بلا
خادم ولا مفتاح. إن خذلتنا الدقة على اللهجة النجدية نبدّل المزوّد خلف نفس الواجهة.

صوت القاضي: `SpeechSynthesis` في المتصفح — مجاني كذلك.

**إلزامي:** يُعرض للاعب نصُّه المحوَّل ليصحّحه قبل إرساله للقاضي. بدونها يحكم القاضي
على كلام لم يُقَل، ويبدو ظالماً واللاعب محق.

## التكلفة

محاكمة = ٦ نداءات، ~٢٤ ألف توكن دخل و~٢ ألف خرج، مع تخزين مؤقت للبرومبت الثابت والقضية
(قراءة الكاش عُشر سعر الدخل، والكتابة ١٫٢٥ ضعف):

| النموذج | المحاكمة | جلسة (٣ محاكمات) |
|---|---|---|
| Opus 5، تفكير عالٍ | ~$0.25 | ~$0.75 |
| Opus 5، تفكير منخفض للتقييم وعالٍ للحكم | ~$0.15 | ~$0.45 |
| Sonnet 5 | ~$0.06 | ~$0.18 |

تقديرات بحدود ±٤٠٪؛ أكبر مجهول توكنات التفكير ولا تُعرف إلا بالقياس.
نبني على Opus 5، وتخفيض التكلفة قرار صاحب المشروع لا قرار المنفّذ.

## المخاطر

| # | الخطر | التخفيف |
|---|---|---|
| ١ | دقة التحويل الصوتي على اللهجة النجدية — **الخطر الأول** | اللاعب يصحّح نصه قبل الإرسال |
| ٢ | تذبذب الحكم: نفس المرافعة تأخذ درجات مختلفة | سلّم درجات صريح + مخرج منظّم |
| ٣ | التأخير: قاضٍ يفكّر ١٥ ثانية يقتل الإيقاع | بثّ التعليق حرفاً بحرف، وتقييم مرافعة الأول أثناء كلام الثاني |
| ٤ | الغش: قراءة بطاقة الخصم أو الدرجات | البطاقات والدرجات في الخادم فقط |

## الحكم

`spoken` جملتان تُنطقان بصوت القاضي، و`reasoning` الحيثيات تُعرض نصاً —
نطق فقرة كاملة ممل، وإخفاء الحيثيات يجعل الحكم تعسفياً.

## ما بُني فعلاً

| الملف | ما فيه |
|---|---|
| `server/rules.js` | المراحل والبطاقات وشرط الفوز — مشتركة بين الخادم والواجهة |
| `server/state.js` | الوكيل الكبير: دوال خالصة، ١٥ اختباراً |
| `server/judge.js` | القاضي: ٣ دوال بمخرج منظّم، وقاضٍ وهمي بلا مفتاح |
| `server/index.js` | HTTP + WebSocket، الغرف، وتدفّق المحاكمة |
| `assets/trial.js` | شاشة المحاكمة — عرض وإدخال فقط |
| `assets/speech.js` | `transcribe()` خلفها Web Speech API |

## بنود مفتوحة

- [ ] لم يُجرَّب القاضي الحقيقي بعد — لا مفتاح في بيئة التطوير. القاضي الوهمي
      يغطي التدفّق كاملاً، لكن جودة الحكم ونبرته لن تُعرف إلا بأول جلسة حقيقية.
- [ ] دقة Web Speech API على اللهجة النجدية غير مقيسة — تُقاس بأول جلسة بصوت حقيقي.
- [ ] استعادة المقعد بعد الانقطاع تسمح لمن يعرف الرمز بأخذ مقعد لاعبٍ منقطع
      ورؤية بطاقاته. مقبول لجلسة بين صاحبين، لا لنشرٍ عام.
- [ ] بثّ تعليق القاضي حرفاً بحرف (streaming) لم يُنفَّذ — التعليق يظهر دفعة واحدة.
