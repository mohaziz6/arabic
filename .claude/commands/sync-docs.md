# تحديث توثيق ديوان التحدي

`CLAUDE.md` هو **ذاكرة المشروع الوحيدة بين الجلسات**: جلسة Claude جديدة تقرؤه ثم تكمل
البناء بلا محادثة سابقة. فكل قرارٍ أو فخٍّ لا يُكتب فيه، يُعاد اكتشافه بالثمن نفسه.

نفّذ الخطوات بالترتيب. **لا تخمّن — اقرأ الكود.**

## ١. اقرأ ما تغيّر فعلاً

```bash
git status --short
git diff --stat HEAD
git log --oneline -8
```

ثم افتح كل ملف تغيّر فعلاً. التوثيق يجب أن يصف **الكود الحالي على القرص**،
لا ما قيل في المحادثة ولا ما كان صحيحاً قبل جولتين.

## ٢. اجمع الأرقام بدل تخمينها

```bash
npm test 2>&1 | tail -6            # عدد الاختبارات الفعلي
grep -c "id:" assets/games.js      # عدد بطاقات الكتالوج
```

كل رقم في التوثيق (عدد الاختبارات، عدد الشاشات، عدد الألعاب المبنيّة، حجم بنك
الكلمات، عدد الشخصيات) يُقرأ من المصدر لا من الذاكرة. **الرقم القديم أسوأ من غيابه**،
لأنه يُصدَّق.

## ٣. حدّث `CLAUDE.md`

مرّ على أقسامه كلها وصحّح ما اختلّ:

- **فكرة المشروع** وأقسام الألعاب — لعبة جديدة تأخذ قسمها الخاص بقواعدها.
- **التقنيات** — مكتبة أو خدمة جديدة، أو فخّ توافق اكتُشف.
- **جداول البنية** (`server/` و`assets/`) — سطر لكل ملف جديد، وتصحيح وظيفة ما تبدّل.
- **المعمارية** — كل قاعدة يكسرها المستقبلُ بصمت (حراسة، خصوصية، طبقات، سباق).
- **قرارات مهمة وأسبابها** — القرار بلا سببه يُنقض في أول مراجعة.
- **أشياء جُرِّبت ولم تنجح** — أهم قسم: يمنع تكرار خطأٍ دفعنا ثمنه مرة.
- **أخطاء حرجة وقعت وأُصلحت** — سياق تاريخي، مع التنصيص أنها **ليست قائمة**.
- **القيود الملخّصة** و**حالة الاختبارات** و**البنود المفتوحة**.
- **آخر ما جرى العمل عليه** و**الخطوة القادمة المقترحة** — أعد كتابتهما بالكامل.

اكتب بالعربية، مختصراً بلا حشو، وبلا نسخ المحادثة حرفياً.

## ٤. حدّث بقية التوثيق

- `README.md` — واجهة المستخدم: لعبة جديدة تُذكر بقواعدها وعدد الاختبارات يُصحَّح.
- `docs/<لعبة>.md` — مواصفة لكل لعبة مبنيّة. لعبة جديدة بلا مواصفة = وثيقة ناقصة.
- تعليقات الكود المضلِّلة — تعليقٌ يصف سلوكاً قديماً أخطرُ من غيابه.

## ٥. تحقّق قبل الالتزام

ابحث عن الأرقام والأسماء التي تشيخ بصمت:

```bash
grep -rn "TRIAL_ONLY\|SANAD_ONLY" CLAUDE.md docs/ README.md   # أسماء أُزيلت
grep -rn "اختبار\|شاشات\|ألعاب" CLAUDE.md README.md | head -20
```

ثم `npm test` — أخضر قبل الدفع، دائماً.

## ٦. التزم وادفع

رسالة الالتزام **بالعربية**، تصف ما تغيّر لا أنه «تحديث توثيق». الفرع
`claude/diwan-challenge-game-design-fq77kt`، ولا تُنشئ Pull Request إلا إن طُلب.

في النهاية، أخبر المستخدم **باختصار** بما حُفظ — لا تُعِد محتوى الملف في المحادثة.
