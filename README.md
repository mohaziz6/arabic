# ديوان التحدي

منصّة ألعاب أدبية عربية بين لاعبَين — كل لاعب من جهازه ونافذته الخاصة، ولا يشترط أن
يكونا في مكان واحد.

**ثلاث ألعاب مبنيّة وتعمل من الطرف للطرف**: «المحاكمة» بقاضٍ وكيل ذكاء اصطناعي،
و«سَنَد» بلا وكيل، و«مَعاني» سباق مفردات. بقية بطاقات الكتالوج أفكارٌ لم تُبنَ بعد.

## التشغيل في ٣ خطوات

يلزمك [Node.js](https://nodejs.org) نسخة 20 أو أعلى، ومتصفح **Chrome أو Edge**
(«المحاكمة» تحتاج Web Speech API؛ اللعبتان الأخريان تعملان على أي متصفح حديث).

```bash
npm install     # مرة واحدة فقط
npm start
```

افتح `http://localhost:8000`. اكتب اسمك، اختر اللعبة، وشارك **رابط الدعوة** الذي
يظهر لك — من يفتحه يجد الرمز جاهزاً ويدخل اللعبة نفسها مباشرة.

**تشتغل فوراً بلا مفتاح API** بقاضٍ وهمي، فتجرّب كل شيء قبل أن تدفع شيئاً.

## المحاكمة — اللعبة الأولى

شاعر متهم في قضية عبثية. لاعب يترافع عنه ولاعب ضده، والقاضي وكيل يسمع الطرفين
ثم ينطق بالحكم. أول من يكسب حكمين يفوز بالجلسة، والأدوار تتبدّل كل قضية.
لكل لاعب **أربعة أسلحة** يرميها على خصمه أثناء مرافعته فتقيّده: قيد الفصحى،
رمية المثل، رمية البيت، والاعتراض. والنقاط تقع على المُقيَّد — كسر القيد فربح
وعجز عنه فخسر — فالرمي مقامرة على عجز خصمك.

قبل كل جلسة تُجرى **قرعة القاضي**: ثلاث بطاقات تهبط والنور يدور عليها حتى يستقر
على أحدهم — **الميزان** العادل الذي يغريه الشعر، أو **الريح** المجنون المتقلّب،
أو **العُرف** شيخ القبيلة الذي يكره التفلسف. لكلٍّ سلّم درجات مختلف، فأسلوب لعبكم
يتغيّر بتغيّر القاضي.

المواصفة الكاملة في [`docs/trial-agent.md`](docs/trial-agent.md).

## سَنَد — اللعبة الثانية

شخصية تاريخية عربية حقيقية، وثلاث روايات عنها: واحدة صحيحة (نقطة)، وكذبة محكمة
(ثلاث)، وكذبة فاضحة (خمس). الراوي يختار سرّاً ويقنع، والخصم يضغط **ثقة** أو **كذّاب**.
والمُحقّ يأخذ نقاط الخيار — فقول الصدق نفسه خدعة مشروعة.

**بلا وكيل ولا مايكروفون**: الحكم للخصم، والتطبيق لوح نقاط وحافظ سرّ، والنقاش
بمكالمة بين اللاعبَين خارج التطبيق. إحدى عشرة شخصية و٩٩ رواية.
المواصفة في [`docs/sanad.md`](docs/sanad.md).

## مَعاني — اللعبة الثالثة

سباق مفردات في ثلاثة مستويات، أربعة أسئلة لكل مستوى:

| المستوى | السؤال | النقاط |
|---|---|---|
| المقابلة | كلمتان — ترادف أم تضاد أم لا علاقة؟ | ١ |
| الحصاد | كلمة وشبكة من ١٥، التقط مرادفها أو ضدّها | ٢ |
| الدخيل | ستّ كلمات يجمعها معنًى… إلا واحدة | ٣ |

السؤال يظهر للخصمين **في اللحظة نفسها**، و**أول من يصيب يأخذ النقاط** ويُغلق
السؤال. ومن أخطأ خرج وحده وبقي الميدان لخصمه. **بلا مؤقّت وبلا وكيل** — الجولة
تنتهي بالإجابة لا بانقضاء الثواني. المواصفة في [`docs/maani.md`](docs/maani.md).

## بقية الألعاب

الأسماء والأوصاف في `assets/games.js` **مبدئية للتقييم** — تُعدّل أو تُستبدل قبل بناء منطق اللعب:

| اللعبة | الفكرة |
|---|---|
| قافية الطايح | يعطيك صدر البيت وتكمّله على وزنه وقافيته |
| الكلمة المحرّمة | تتكلم في موضوع بدون أن تنطق كلمات ممنوعة |
| مرثية الشاحن | ترثي شيئاً تافهاً بقصيدة |
| سيف وقلم | مساجلة هجاء ظريف متبادلة بين اللاعبَين |
| تفسير الطلاسم | تفسّر عبارة بلا معنى بأسلوب النقّاد |
| مدح الخصم | مدح ظاهره ثناء وباطنه لؤم |

## التصميم

طابع صحراوي نجدي فاتح بروح عصرية: خلفية رملية شبه بيضاء، بطاقات نظيفة، وذهب باهت للتركيز.
العناوين الكبيرة بخط **Aref Ruqaa** والمتن بـ **IBM Plex Sans Arabic** — الخطان مستضافان
محلياً في `assets/fonts/` بلا اعتماد على الشبكة. اللمسات النجدية محسوبة: شريط مثلثات كفاصل،
وأقواس طينية تحمل حروف الألعاب.

خلفية الصفحة صحف معلقات على `canvas`: تنجرف ببطء، تبتعد عن مؤشر الماوس كأن الهواء يدفعها،
وتنفجر متطايرة عند الضغط. **كل الأصوات مولَّدة بـ Web Audio — بلا ملفات صوت وبلا موسيقى.**
وكل الحركات تحترم `prefers-reduced-motion`.

## للقاضي الحقيقي

أنشئ ملف `.env` في جذر المشروع:

```
ANTHROPIC_API_KEY=sk-ant-...
```

المفتاح من [console.anthropic.com](https://console.anthropic.com) ← API Keys.
أعد `npm start`، ويطبع لك `القاضي: claude-opus-5`.
**المفتاح لا يغادر الخادم**، وكذلك البطاقات والدرجات وأجوبة الأسئلة.

## للعب من جهازين بالصوت

المتصفحات تمنع المايكروفون إلا على `localhost` أو `https`، فمن يدخل من جواله
على `http` سيلعب «المحاكمة» بالكتابة. للصوت عند الطرفين:

```bash
npm run https
```

يطبع لك عنوان `https://192.168.x.x:8443` — افتحوه من الجهازين. سيحذّر المتصفح
مرة واحدة من الشهادة المحلية: «متقدم» ثم «متابعة»، ثم يعمل المايكروفون.

> «سَنَد» و«مَعاني» لا تستخدمان المايكروفون أصلاً، فتعملان على `http` بلا شيء.

## أوامر أخرى

```bash
npm test                 # ٧٦ اختباراً: آلات الحالات + من الطرف للطرف
PORT=8080 npm start      # منفذ آخر لو كان 8000 مشغولاً
```

## البنية

```
index.html               ست شاشات في صفحة واحدة، بلا راوتر
assets/styles.css        نظام التصميم كله (متغيرات CSS، بلا لون مباشر)
assets/games.js          كتالوج الألعاب — بيانات فقط
assets/app.js            التنقل واختيار اللعبة وتوجيه رابط الدعوة
assets/trial.js          شاشة المحاكمة   ← server/state.js + server/judge.js
assets/sanad.js          شاشة سَنَد       ← server/sanad.js
assets/maani.js          شاشة مَعاني      ← server/maani.js
server/index.js          HTTP + WebSocket، الغرف، عزل الألعاب عن بعضها
```

كل لعبة آلةُ حالات **خالصة** في الخادم (بلا شبكة ولا نموذج لغوي)، والمتصفح لا يرى
إلا لقطة `viewFor` الخاصة به — فأسرار الخصم لا تُرسل أصلاً، لا تُحجب بالـ CSS.
