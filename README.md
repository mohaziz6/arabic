# ديوان التحدي

لعبة أدبية بين لاعبَين — كل لاعب من جهازه ونافذته الخاصة — والحكم وكيل ذكاء اصطناعي
يسمع الأصوات، يقيّم الإجابات، ويولّد أسئلة جديدة في كل جولة.

## حالة المشروع

**المرحلة الحالية: التصميم فقط.** الواجهة مبنية بدون منطق لعب وبدون اتصال شبكي —
كل الحالة محلية في المتصفح، والغرض هو تثبيت الشكل والانطباع قبل بناء اللعب والحكم.

## الشاشات

1. **البدء** — اسم اللاعب، وإنشاء ديوان (يولّد رمزاً من ٤ خانات) أو الانضمام برمز.
2. **اختيار اللعبة** — شريط اللاعبَين، وشبكة بطاقات الألعاب، وبطاقة «نصيبك من الديوان» للاختيار العشوائي.
3. **الاستعداد** — تأكيد اللعبة المختارة، ومشاركة الرمز، وانتظار الخصم.

## التصميم

طابع صحراوي نجدي فاتح بروح عصرية: خلفية رملية شبه بيضاء، بطاقات نظيفة، وذهب باهت للتركيز.
العناوين الكبيرة بخط **Aref Ruqaa** والمتن بـ **IBM Plex Sans Arabic** — الخطان مستضافان
محلياً في `assets/fonts/` بلا اعتماد على الشبكة. اللمسات النجدية محسوبة: شريط مثلثات كفاصل،
وأقواس طينية تحمل حروف الألعاب.

خلفية الصفحة صحف معلقات على `canvas`: تنجرف ببطء، تبتعد عن مؤشر الماوس كأن الهواء يدفعها،
وتنفجر متطايرة عند الضغط على «ابدأ» أو اختيار لعبة. تحترم `prefers-reduced-motion`.

## الألعاب

الأسماء والأوصاف في `assets/games.js` **مبدئية للتقييم** — تُعدّل أو تُستبدل قبل بناء منطق اللعب:

| اللعبة | الفكرة |
|---|---|
| قافية الطايح | يعطيك صدر البيت وتكمّله على وزنه وقافيته |
| الكلمة المحرّمة | تتكلم في موضوع بدون أن تنطق كلمات ممنوعة |
| مرثية الشاحن | ترثي شيئاً تافهاً بقصيدة |
| سيف وقلم | مساجلة هجاء ظريف متبادلة بين اللاعبَين |
| تفسير الطلاسم | تفسّر عبارة بلا معنى بأسلوب النقّاد |
| مدح الخصم | مدح ظاهره ثناء وباطنه لؤم |

## التشغيل

افتح `index.html` في المتصفح مباشرة، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

```
index.html          الشاشات الثلاث
assets/styles.css   نظام التصميم (ألوان، بطاقات، حركات)
assets/games.js     كتالوج الألعاب — عدّل هنا لإضافة أو تغيير لعبة
assets/app.js       التنقل بين الشاشات واختيار اللعبة
```

## الخطوة القادمة

بعد اعتماد التصميم: تحديد أنواع الجولات وقواعد التقييم، ثم بناء غرفة اللعب
(اتصال لحظي بين الجهازين)، ثم وكيل الحكم — التقاط الصوت، تحويله نصاً، التقييم،
والردّ بصوت الحكم.
